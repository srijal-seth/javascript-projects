# Frontend-4 (JS Projects)

This repository contains small JavaScript front-end projects built to practice DOM manipulation, styling, and interactive UI behavior.

## Project Overview

### 1. JavaScript Background Color Switcher
- Folder: `01-javascript-project/`
- Description: A simple app where clicking color buttons changes the background color of the page.
- Tech used: HTML, CSS, JavaScript

#### Files
- `01-javascript-project/index.html`
- `01-javascript-project/style.css`
- `01-javascript-project/script.js`

#### How to run
1. Open the `01-javascript-project` folder.
2. Open `index.html` in your browser.
3. Click any color button to change the page background.

## Learning Focus
- JavaScript event listeners
- DOM selection with `querySelector` and `querySelectorAll`
- Changing CSS styles dynamically using JavaScript

## Notes
This is a beginner-friendly project collection for improving front-end JavaScript skills.
